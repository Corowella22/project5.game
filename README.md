🕹️ TempleOS Type Game

A retro-styled typing game inspired by the divine aesthetics of TempleOS.

---

📦 Установка

1. Установите Python

Скачайте и установите Python с официального сайта:
➜ https://www.python.org/downloads/

Для Windows пользователей: инструкция

2. Скачайте игру

Скачайте архив с файлом TERRY.py и распакуйте в удобную директорию.

3. Установите зависимость

Откройте терминал и выполните:

```bash
pip install pygame
```

4. Запустите игру

Перейдите в папку с игрой:

```bash
cd путь/к/папке
```

Запустите:

```bash
python TERRY.py
```

(или python3 TERRY.py на macOS/Linux)

---

⚙️ Важно

· Игра требует английской раскладки клавиатуры
· Убедитесь, что pygame установлен корректно
